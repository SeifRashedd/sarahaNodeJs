Saraha API Tester

1. Signup POST /auth/signup

Use a real email you can open — the OTP is sent to it.

2. Confirm email POST /auth/confirm_email

Wrong code → 401 with trials left. 5 wrong codes → 429 blocked for 15 min (resend blocked too).

3. Resend OTP POST /auth/resend_otp

409 while the old code is still valid (5 min). After 5 sends → 429 blocked for 15 min.

4. Login POST /auth/login

403 if the email is not confirmed yet. Tokens are saved automatically.

5. Forget password POST /auth/forget_password

Sends a reset code to the email. After 5 sends → 429 blocked for 15 min.

6. Verify reset code POST /auth/verify_forget_password_otp

Right code → you have 5 min to do step 7. Wrong code → 401, 5 wrong → 429.

7. Reset password POST /auth/reset_password

403 if step 6 wasn't done. After reset, old tokens stop working (logout everywhere).

8. Logged-in requests

Use the saved tokens (login first).

rotate_token returns 409 until the access token expires.
